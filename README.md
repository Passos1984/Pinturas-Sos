# 🎨 SOS Pinturas - Formulário de Orçamento Rápido

Um sistema simples, direto e responsivo para solicitação de orçamentos de serviços de pintura diretamente pelo WhatsApp. Criado para facilitar e agilizar o contato inicial entre clientes e prestadores de serviço.

🔗 **Acesse o projeto online:** [https://tinyurl.com/sospinturas](https://tinyurl.com/sospinturas)

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do formulário.
* **CSS3:** Estilização customizada, layout responsivo e criação de efeito visual de textura de parede via Base64.
* **JavaScript (Vanilla):** Captura dos dados do formulário, formatação da string de texto e integração com a API do WhatsApp.

## ✨ Funcionalidades

* Interface amigável e responsiva (adapta-se perfeitamente a celulares e computadores).
* Design customizado voltado para o nicho de pintura e reformas.
* Fundo do cabeçalho com textura customizada em SVG (simulando reboco/parede).
* Botão flutuante de contato rápido.
* Redirecionamento automático para o WhatsApp do profissional com a mensagem de orçamento já pré-formatada e organizada.

## 🚀 Como testar o projeto localmente

1. Faça o clone deste repositório na sua máquina ou baixe o arquivo ZIP.
2. Extraia os arquivos e abra o `index.html` no seu navegador (Chrome, Edge, Firefox, etc.).
3. Preencha os dados do formulário de teste.
4. Clique em "SOLICITAR ORÇAMENTO NO WHATSAPP" para ver a mágica da API funcionando.
